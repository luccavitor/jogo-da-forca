# Jogo da Forca

Um jogo da forca desenvolvido em **C++**, utilizando conceitos fundamentais de programação, como funções, estruturas de repetição, condicionais e variáveis booleanas.

## Sobre o projeto

O objetivo do jogo é adivinhar a palavra secreta por meio de tentativas com letras. O programa verifica se a letra digitada pelo jogador está presente na palavra escolhida e apresenta uma mensagem informando se o chute foi correto ou incorreto.

## Tecnologias utilizadas

- **Linguagem:** C++
- **Bibliotecas:**
  - `iostream` — entrada e saída de dados.
  - `string` — manipulação de textos.

## Conceitos aplicados

- Declaração de variáveis e constantes.
- Funções com retorno booleano (`bool`).
- Estrutura de repetição `while`.
- Estrutura condicional `if/else`.
- Laço `for` baseado em intervalo (*range-based for*).
- Comparação de caracteres.
- Entrada de dados com `cin`.
- Saída de dados com `cout`.

## Funcionamento

A palavra secreta definida no código é **MELANCIA**.

O jogador deve digitar uma letra por tentativa. O programa verifica se ela existe na palavra secreta e informa o resultado.

## Objetivo de aprendizagem

Este projeto foi desenvolvido com o objetivo de praticar e consolidar os fundamentos da linguagem C++, aplicando estruturas de controle, funções e lógica de programação em um projeto prático.
